# Contributing to SIZU

Thank you for your interest in SIZU Portal. Please open an issue describing a bug, accessibility improvement, or feature before substantial changes. Fork the repository, make a focused branch, run `npm install`, `npm run lint`, and `npm run build`, and open a pull request with testing notes. Never include personal data or secrets in issues, commits, or pull requests. Respect the separate SIZU branding guidance in `BRANDING.md`.
