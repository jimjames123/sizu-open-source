# Security policy

Please do not disclose security vulnerabilities or personal information in public GitHub issues. Contact the SIZU maintainers privately through the official contact details at https://sizuportal.org.

Never commit Supabase service-role keys, passwords, private keys, access tokens, database exports, or user data. Public Vite environment variables must contain only client-safe publishable configuration. Enable and review Supabase Row Level Security policies before deploying.
